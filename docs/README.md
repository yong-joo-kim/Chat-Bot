# docs 폴더 구조

챗봇 시스템 개발을 위한 문서 보관 위치입니다. 아래 순서로 채워집니다.

| 폴더 | 용도 | 상태 |
|---|---|---|
| `00-source/` | **사용자가 원본 챗봇 기술문서·개발 가이드 문서를 저장하는 위치** | 문서 대기 중 |
| `01-requirements/` | `00-source/` 문서를 분석해 정리한 개발요구기능 목록 | 추후 생성 |
| `02-spec/` | 개발명세서 | 추후 생성 |
| `03-design/` | 개발설계서, 디자인 시안 | 추후 생성 |
| `04-test/` | 시험계획, 시험항목, 시험데이터, 자동시험/오류검출 결과 | 추후 생성 |
| `05-ops/` | 자동배포, 버전관리 관련 문서 | 추후 생성 |

## 진행 순서

1. 원본 챗봇 기술문서와 개발 가이드 문서를 `00-source/`에 저장한다.
2. Claude가 `00-source/`의 문서를 분석하여 제공 기능을 세부 항목으로 정리한다.
3. 분석 결과를 바탕으로 `01-requirements/` ~ `05-ops/`를 순서대로 채우고, 멀티에이전트 구성(`.claude/agents`, `SKILL.md` 등)을 계획한다.
4. 사용자 승인 후 개발을 진행한다.
