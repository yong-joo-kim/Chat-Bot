## 갱신 (2026-10-01 — PM 결정 K-1b: "모든 실패의 G1 수렴"을 런타임에 실구현 · ADR-0049 §1)

§2의 문구는 불변이다 — 구현이 문구를 따라잡는다. 포트 1 + 구현 3종·팩토리 1곳·강제 5단계·출구 게이트·`/augment` 계약 **불변**.

1. **폴백 위치 = 러너 1곳**: 설정된 Provider가 `gemini`·`local`이고 **사용 가능한 후보(공백 아닌 문자열) 0건**이면 러너가 팩토리 `getFallbackProvider()`(항상 G1)로 같은 Job 안에서 **1회** 다시 생성한다. G1도 0건이면 기존 `PARTIAL`. `rule`·`mock` 구성은 폴백하지 않는다.
2. **원인은 반환값으로**: 포트에 선택 메서드 `generateWithOutcome?()`(`{ candidates, failure? }` — 예외 전파 금지)를 더한다. 원인 코드 10종(`TIMEOUT`·`NETWORK`·`HTTP_4XX`·`HTTP_5XX`·`INVALID_RESPONSE`·`EGRESS_BLOCKED`·`CIRCUIT_OPEN`·`SEED_BLOCKED`·`NOT_CONFIGURED`·러너 판정 `EMPTY_RESULT`)은 **표시·로그 전용**이며 폴백 여부를 바꾸지 않는다(계약 C-6). `generate()` 서명·C-1 불변.
3. **부분 성공은 보충하지 않는다**(G2/G3가 1건이라도 내면 G1 호출 0) · **재시도 0**(30초 × 2가 콘솔 폴링 상한 60초 초과).
4. **표시**: 제안 행 `providerId='rule'`(기존 컬럼) · 결과 요약 `degraded:true`(기존 필드 — 이전엔 한 번도 쓰이지 않음) + 선택 `fallbackFrom`·`fallbackCause` · 화면은 FR-L1-7 문구 1줄. 폴백이 없으면 결과 요약 키가 지금과 같다(바이트 동일). 감사·알림·새 컬럼 0.
5. **거버넌스(No.45)**: 출구 차단(`EGRESS_BLOCKED`)도 G1 결과로 채워진다 — 새 출구·송신 0 · 데이터 지도 불변.
6. **관찰 K-1c**: 위 §2 "연속 5회 실패" 행 각주 — 회로차단은 Job 단위 인스턴스라 사실상 미발동. 이번 범위 밖.
```

## 갱신 (2026-10-01 — PM 결정 L-5: 저장·송신 경로도 날짜 제외 · 규칙 v2 · 과거 저장분 불변)

**ADR-0049 §4**. 정책(대상 5종·차등)·함수 1벌·순서(금지어 → PII → 암호화)·`PII_MASK_MODE`·출구 종류 선택은 **불변**이다. 바뀌는 것은 계좌 판정의 날짜 오인 **1가지**다.

1. **규칙 v2**: 기본 호출(`maskPii(text)`·`maskPii(text, { mode })`)의 계좌 치환에서 독립 날짜 `YYYY-MM-DD`(1900~2099 · 월 01~12 · 일 01~31 · 앞뒤가 숫자·하이픈 아님 — 출구 날짜 규칙과 **같은 1벌**)를 건너뛴다. 날짜 범위 밖(`2026-13-01`)·경계 위반(`12026-09-30`·`2026-09-30-12`)·`YY-MM-DD`는 여전히 `[계좌번호]`(fail-closed). 점·슬래시·한글 날짜는 원래 대상이 아니었다.
2. **`preserveDates`**: 제거하지 않고 **생략 = true**로 뒤집는다. `false`는 구 규칙 v1과 바이트 동일 — 가드레일 출구의 "날짜 보호 끔" 설정이 계속 쓴다. 선택 인자를 넘기는 운영 호출 파일은 여전히 출구 1파일(정적 검사 불변).
3. **적용 지점 8곳 전부**(저장 · RAG 질의 · 증강 · 레거시 · 웹훅 · 인박스 · KB 적재 · 출구)에 호출부 수정 없이 적용된다. 레거시·웹훅의 날짜 슬롯이 `[계좌번호]` 대신 실제 날짜로 나가고, KB 원본 파일의 PII 건수에서 날짜가 빠진다(거버넌스 ON 원본 파일 게이트 판정 변화 — 설계서 §5.9).
4. **과거 저장분은 재마스킹·되돌림·백필하지 않는다**(No.45 FR-DG9-3 "이후 적재분에만"). 한 테이블 안에 v1(날짜 가림)·v2(날짜 원문) 행이 공존한다. KB 적재 변환 규칙 버전은 올리지 않는다.
5. **골든**: 구현 전 말뭉치를 `storage-corpus.v1.json`으로 동결하고 날짜 케이스만 갱신(예상 306건 중 23건) — "v1 = `preserveDates:false`"·"달라진 케이스 = 닫힌 목록"·"기본 경로 ≡ 선택 경로(5종)"를 시험으로 고정. 전체 재생성 금지는 유지.
6. **감수 비용 추가**: 하이픈 날짜형 생년월일 등 5종 밖 정보가 더는 **우연히** 가려지지 않는다(PM 확인 U-1). 규칙 버전(`PII_MASK_RULES_VERSION = 2`)은 기동 로그로 확인한다(폐쇄망 반입 빌드의 구 `dist` 잔존 확인).
```

## 갱신 (2026-10-01 — ADR-0049: §4 날짜 부분 · §5 끄기 잠금 기본값 부분 대체 · L-2 수용)

2026-10-01 PM 결정(결함분류 `docs/04-test/결함분류-2026-10-01.md` K-1b·N36-1·L-2·L-5). 규칙 모델·입구/출구 지점·`FAILED` 수렴·이벤트·2인 승인 강제 지점·상태 기계·권한은 **불변**이다.

2. **§5(끄기 잠금)**: `ENV_APPROVAL_OFF_LOCKED`는 3상태 — **명시값 우선**, 미설정이면 `DATA_GOVERNANCE_MODE=ON`일 때 잠금. 현황 `offLocked` 의미 불변 + 잠금일 때만 선택 필드 `offLockedBy`. 오류 코드·사유(`OFF_LOCKED`) 불변. 원 설계 U-7("모드와 무관")은 **기본값에 한해 번복**, 명시 설정은 여전히 모드와 무관.
