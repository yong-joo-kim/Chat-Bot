```
## 갱신 (2026-10-01 — 후속 T-5·L-6: 긴 숫자열 카드 우선 · 규칙 v3 · 이메일 탐지 선형화)

**ADR-0050 §1·§3**. 정책(대상 5종·차등)·함수 1벌·순서(주민번호 → 카드 → 전화 → 계좌 → 이메일)·`PII_MASK_MODE`·출구 종류 선택·날짜 제외(v2)는 **불변**이다.

1. **§3 불변식 ②의 부분 이행**: 주민번호 **연속형**(하이픈 없음)은 앞뒤가 숫자가 아닌 정확히 13자리일 때만 주민번호다(하이픈형 불변). 카드 단계는 앞뒤가 숫자가 아닌 **14자리 이상 숫자 연속 전체**와 **AMEX 4-6-5**(같은 구분자)를 먼저 본다. 16자리 카드가 `[주민등록번호]111`로 쪼개지던 결함(T-5)을 없앤다. **체크섬(Luhn·주민번호)은 여전히 쓰지 않는다** — 저장 경로에서 검증 실패를 원문 유지로 처리하면 오타 난 실제 카드·2020-10 이후 체크섬이 맞지 않는 실제 주민번호를 놓친다(fail-closed). 위 "구현 확인(2026-09-20)"의 "2단계 미구현"은 체크섬 분류에 한해 그대로다.
2. **규칙 v3**: 바뀌는 입력은 길이 14 이상 숫자 연속 또는 AMEX 형식을 가진 입력뿐이며 그 밖은 v2와 바이트 동일(골든 v2 동결 + 차분 시험). 바이트 불변 원칙의 두 번째 의도적 예외(더 가리는 방향). **과거 저장분 재마스킹 없음.** 기동 로그 `pii-mask 규칙 v3(…)`.
3. **출구**: 기본(주민번호·카드)에서 16자리 연속·AMEX 하이픈형이 `[카드번호]`로 가려진다. "카드 끔 + 주민번호 켬"(거버넌스 OFF에서만 가능)에서는 16자리 연속이 원문으로 나간다.
4. **이메일 탐지 선형화(L-6)**: 결과를 바꾸지 않는다(규칙 버전 불변). 시작 위치를 로컬 문자 연속의 처음 또는 직전 일치의 끝으로 제한한다 — 기존 골든 무수정 통과 + 구 정규식 오라클 차분 퍼징으로 고정.
5. **남은 미탐(기록)**: 13자리 연속(7번째 자리 0·9) · 4-4-4-4-3(19자리)의 끝 3자리 · Diners 4-6-4 공백형 · 전각 숫자 · 제로폭 문자로 쪼갠 숫자.
```

```
## 갱신 (2026-10-01 — 후속 K-1c·K-1d: 회로 상태의 프로세스 공유 · local 회로 · 폴백 예외 방어 · ADR-0050 §2·§4)

§2의 문구("연속 5회 실패 → 회로 open 60초 → 그동안 G1 직행")는 불변이고 구현이 따라잡는다. 포트 1 + 구현 3종·팩토리 1곳·강제 5단계·출구 게이트·`/augment` 계약 **불변**.

1. **수명**: 회로 **상태**를 팩토리(모듈 싱글턴)가 공급자별(`gemini`·`local`)로 지연 생성·소유하고, Job마다 만드는 Provider에 주입한다. Provider 인스턴스는 캐시하지 않는다(Gemini의 Job별 금지어 입력이 낡지 않게). `rule`·`mock` 구성에서는 회로도 생성되지 않는다(AC-L1-14).
2. **실패 정의**: 인프라 실패(타임아웃·네트워크·5xx·429)만 계수한다. 그 밖의 4xx·형식 오류·출구 차단은 중립, 정상 응답은 연속 실패를 초기화. 시드 금지어·키 없음은 회로를 건드리지 않는다(Gemini는 시드 마스킹·금지어 검사를 회로 확인보다 먼저 — §3 5단계 순서).
3. **half-open**: 개방 시간 경과 후 첫 호출 1건만 탐침 · 성공/중립 → 닫힘 · 실패 → 재개방 · 개방 전 시작된 호출의 늦은 실패는 개방을 연장하지 않는다.
4. **local 포함**: 응답 정지형 장애에서 Job마다 30초 대기를 없앤다. 개방 중 원인 코드 `CIRCUIT_OPEN` → 러너가 같은 Job에서 G1 폴백(갱신 2026-10-01 K-1b).
5. **설정**: `AUGMENTATION_CIRCUIT_FAILURE_THRESHOLD`(기본 5) · `AUGMENTATION_CIRCUIT_OPEN_MS`(기본 60000 · 하한 1000). 다중 인스턴스는 인스턴스마다 독립. Gemini 회로 개방 중 capability는 `UNHEALTHY`를 보고한다.
6. **K-1d**: 러너의 폴백 G1 조달·생성 예외는 후보 0건 `PARTIAL` + 기존 폴백 키(`fallbackCause`는 1차 원인 유지)로 수렴한다 — Job `FAILED` 아님 · 로그는 오류 이름만(문장·메시지 0).
```
