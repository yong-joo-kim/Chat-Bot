## 1. 목적 및 분류 기준

RoCHA.AI(페르소나AI) 제품소개서·매뉴얼을 분석하여 챗봇 솔루션의 기능을 아래 3단계로 구분한다.

- **기본기능**: 챗봇 운영에 필수적인 기초 관리/제작/모니터링 기능
- **확장기능**: 딥러닝 기반 고도화, 대량 검증, 하이브리드 상담 등 차별화·고급 운영 기능
- **옵션(신규 제안)**: 원본 문서(2023~2024년 작성)에는 없는 2025~2026년 업계 최신 트렌드 기능 후보

**GPU 필요도 (1~10)**
| 구간 | 설명 | 예시 |
|---|---|---|
| 1~2 | CPU 전용 — CRUD/설정/통계조회/규칙매칭 | 대시보드, 회원관리, 대화그래프 빌더 |
| 3~4 | 경량 ML(CPU 가능) — 소규모 분류/배치학습 | 의도 학습, FAQ 자동완성 |
| 5~6 | 중간 딥러닝(GPU 권장) — 임베딩/증강학습 | Text Embedding, DLE 증강학습 |
| 7~8 | LLM/비전 모델(GPU 필수) | 생성형AI+RAG, 딥러닝 군집분석 |
| 9~10 | 대규모 동시 서빙(GPU 클러스터 필수) | 본 문서 범위 밖 |

**구축형(On-Premise)/구독형(SaaS) 적합도**: ○ 적합 · △ 부분적합(조건부) · ✕ 비권장/제한적
- 구축형: 고객사 자체 서버에 엔진까지 설치. 보안·커스터마이징 강점, 초기 GPU 인프라 투자 필요
- 구독형: 벤더/클라우드 제공, 초기 투자 부담 적음, GPU 자원은 벤더 부담
